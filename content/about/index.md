# 关于 CodeLab
CodeLab 是一个记录后端开发与 AI Agent 实践的个人博客，主要分享技术知识、实战项目，以及在工作中积累的经验与思考。

我希望通过持续记录和复盘，把零散的实践沉淀为可复用的知识，也和同样关注后端开发与 AI Agent 的朋友交流学习。
