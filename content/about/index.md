# 关于 CodeLab
CodeLab 是一个专门记录后端和Agent的博客网站，旨在分享和学习后端开发和AI Agent相关的知识。同时也会分享一些实战项目，和在工作中的沉淀学习到的东西。

# 作者
哈喽兄弟们，我是程序员羊肉。小红书博主一枚，我一开始就是在小红书起号，通过分享学习经验，到目前为止收获了2500个粉丝。

至于 CodeLab，我是出于做个人博客的出发点来做的，想记录一些自己平时学习到的知识，然后沉淀出一套属于自己的方法论，希望能帮助到更多的人。当然，也可以把 CodeLab 当成知识社区，有意愿的兄弟也可以来贡献自己的知识，欢迎大家来提pr。
